# Renderer task

Build only `src/lettercraft/view.js`, standalone plain browser JS defining `class LettercraftView`. Do not edit any other source file, do not commit, and do not spawn agents. Parent builds engine, input, UI and bundler concurrently. Read this brief first; no need to read whole repo.

World is vibrant Minecraft-inspired original block art, 2.5D isometric Canvas with soft daylight sky background and floating grassy island 32x32. Draw visually polished block trees (trunks + cubes of foliage), stone/ore boulders, friendly sheep block animals, hostile block monsters, block explorer with visible face/eyes, hair, backpack and tool. Character and tool face mouse (angle below). Ground paths at grid x or y around16 or multiples of4, green meadow, tiny flowers/grass tufts, island soil sides. Original canvas art only, no network/assets. Readable upright letter plaques with dark background and dotted-circle Thai combining marks. White/yellow hovered outlines, HP bars, pickup progress ring, shadows, swing animation, invulnerability flicker, decorative particles. Show small minimap top right inside canvas, dots for resources and nearby enemies, player marker. Camera follows smoothly, works 640x480 to full desktop. Player should remain center area, HUD occupies top 85px and bottom110px external canvas overlays.

API: constructor(canvas); resize() measures canvas CSS bounds, caps DPR at2, updates this.width/height; project(x,y,z=0) -> {x,y} in canvas CSS coordinates; unproject(sx,sy) -> world {x,y}; render(game, dt, hoverId=null) -> draws and updates camera, not simulation; pick(game,sx,sy) -> nearest topmost entity id or null using cached screen bounds from latest render. Coordinate formula recommended x=(worldX-worldY)*32, y=(worldX+worldY)*16; scale responsive but inverse consistent. Expose properties width,height. Initial camera must be valid before first pointer event. Arrow movement engine adapter will convert screen axes into world directions separately.

game: size=32; player={x,y,angle,swing} angle in world coordinates atan2(dy,dx); hearts 0..5; invulnerable seconds; status='ready'|'playing'|'won'|'lost'; elapsed seconds; entities=[{id,kind:'tree'|'rock'|'animal',x,y,char,hp,maxHp,stun}]; enemies same shape kind='enemy'; drops=[{id,kind:'letter'|'tool',char?,tool?:'pickaxe'|'axe'|'sword',x,y}]; tools={pickaxe:0..2,axe:0..2,sword:0..2}; collecting=null or {dropId,elapsed:0..3}; goals object mapping char -> required total; inventory object mapping char -> collected total; selectedDrop() returns nearest eligible drop or null; events=[{kind:'hit'|'break'|'collect'|'hurt'|'tool',x,y,char?,tool?}] optional consume? DO NOT mutate events; parent will drain after rendering; handle each at most once via unique event.id if you use them. Entities may vanish between frames. No UI or DOM event listeners beyond canvas size; bridge calls resize. Guard invalid canvas dimensions.

Please create focused renderer with no module imports; parent will inline into index. Optional CommonJS export guarded typeof module for renderer unit tests if helpful. Verify node --check src/lettercraft/view.js; parent handles browser screenshot QA. Report final only status, file, validation, concerns.
