# แผนออกแบบเกมโลกบล็อกเก็บตัวอักษร

> ฉบับประวัติการออกแบบ 2.5D: ผู้ใช้เปลี่ยนเป็น 3D มุมมองบุคคลที่หนึ่งแล้ว ดูข้อกำหนดที่ใช้ปัจจุบันใน `2026-09-09-lettercraft-first-person.md` และผลตรวจล่าสุดใน `../lettercraft-progress.md`

สถานะ: ผู้ใช้ยืนยันแบบแล้ว — พัฒนาเสร็จในเครื่อง ผ่านชุดทดสอบ 25 กรณีและทดสอบ Chrome; ยังไม่เผยแพร่ขึ้นเว็บจริง

ใช้กระบวนการ Superpowers brainstorming เพื่อแยกความต้องการ กำหนดรูปแบบการเล่น และระบุเกณฑ์ตรวจรับก่อนลงมือพัฒนา

## 1. เป้าหมายและข้อกำหนดที่ยืนยันจากผู้ใช้

แทนที่เกมท้ายบทเรียนเดิมทั้ง 4 ธีมด้วยเกมเดียว เด็กเดินสำรวจแมพสไตล์โลกบล็อก พบตัวอักษรอยู่บนต้นไม้ หิน สัตว์ และมอนสเตอร์ ใช้เมาส์ฟันหรือขุดให้ตัวอักษรดรอป แล้วกดปุ่มตัวอักษรนั้นค้างเพื่อเก็บ

- คลิกเมาส์เพื่อฟันหรือขุด ไม่ใช้ปุ่มตัวอักษรในการโจมตี
- ตัวอักษรเป็นของดรอปที่ต้องกดปุ่มตรงตัวค้างต่อเนื่อง 3 วินาทีเพื่อเก็บ
- มีอาวุธและเครื่องมือดรอป ช่วยให้ฟันหรือขุดเร็วขึ้น
- จำกัดเวลารอบละ 5 นาที
- เริ่มต้นด้วยหัวใจ 5 ดวง โดนโจมตีสำเร็จ 5 ครั้งจะแพ้
- มีมอนสเตอร์วิ่งเข้ามาโจมตีผู้เล่น
- มีคำอธิบายวิธีเล่นในเกม
- เดินได้ทั้งปุ่ม WASD และปุ่มลูกศร โดยให้ทิศทางและความเร็วเท่ากัน
- ตัวละครหันหน้าตามตำแหน่งเมาส์ และฟันหรือขุดไปทางที่เมาส์ชี้

การแก้ไขล่าสุดของผู้ใช้มีผลเหนือแนวคิดเดิม: การขุด/ฟันใช้เมาส์ ส่วนการกดตัวอักษรค้างใช้เฉพาะเก็บของที่ดรอปแล้ว

## 2. รูปแบบภาพและมุมมองที่เสนอ

แนะนำโลกบล็อก 2.5D มุมมองเฉียง กล้องตามตัวละคร ตัวละคร ต้นไม้ หิน และมอนสเตอร์มีรูปทรงเหลี่ยม ภาพสีสว่างเป็นมิตรกับนักเรียน มีแสงเงาและเอฟเฟกต์เศษบล็อกเมื่อถูกตี ใช้งานบนคอมพิวเตอร์พร้อมคีย์บอร์ดและเมาส์เป็นหลัก

แนวทางที่พิจารณา:

| แนวทาง | จุดเด่น | ข้อแลกเปลี่ยน |
| --- | --- | --- |
| โลกบล็อก 2.5D มุมเฉียง — แนะนำ | เห็นภัยรอบตัว อ่านตัวอักษรง่าย ควบคุมกล้องง่าย ใช้ Canvas ที่ระบบมีอยู่ | ไม่ใช่การเดินมุมมองบุคคลที่หนึ่ง |
| โลกบล็อก 3D บุคคลที่หนึ่ง | ให้ความรู้สึกเดินในโลกใกล้เคียงเกม Minecraft มากขึ้น | ต้องควบคุมกล้องและล็อกเมาส์ เพิ่มภาระการเรนเดอร์และงานทดสอบ |
| โลกบล็อก 3D บุคคลที่สาม | เห็นตัวละครและความลึกของโลก | ต้องจัดการกล้องชนฉากและวัตถุบังตัวอักษร |

ใช้ภาพและรูปทรงที่สร้างสำหรับโปรเจกต์นี้ ชื่อชั่วคราวในเกมคือ “นักสำรวจโลกอักษร / Lettercraft Adventure”

## 3. วงจรการเล่น

1. ผ่านแบบฝึกหัด → กด “เล่นเกมนักสำรวจโลกอักษร”
2. อ่านวิธีเล่นและเป้าหมาย → กด “เริ่มสำรวจ” แล้วเริ่มนับเวลา
3. เดินหาเป้าหมายที่มีป้ายตัวอักษรติดอยู่
4. เข้าใกล้ ชี้เมาส์ แล้วคลิกซ้ายฟันหรือขุดจนแถบความทนทานหมด
5. ตัวอักษรและอุปกรณ์ที่ได้ตกลงบนพื้น
6. เข้าใกล้ตัวอักษร กดปุ่มตรงกับป้ายค้าง 3 วินาทีจนวงแหวนเต็ม
7. รับตัวอักษรเข้าภารกิจ ใช้เครื่องมือใหม่ และหลบหรือต่อสู้กับมอนสเตอร์
8. เก็บครบก่อนหมดเวลาและยังมีหัวใจ → ชนะ; หัวใจหมดหรือครบ 5 นาที → จบรอบแบบแพ้

## 4. การควบคุม

| การกระทำ | การควบคุม | ผลตอบกลับที่แสดง |
| --- | --- | --- |
| เดิน | W / ↑ ขึ้น, A / ← ซ้าย, S / ↓ ลง, D / → ขวา | ตัวละครเดินตามทิศทางบนหน้าจอ กล้องตามอย่างนุ่มนวล ทั้งสองชุดปุ่มมีความเร็วเท่ากัน |
| หันตัวละคร | เลื่อนเมาส์รอบตัวละครในพื้นที่เกม | ตัวละครและอาวุธหันตามเมาส์โดยไม่ต้องคลิก และไม่หมุนกล้อง |
| เลือกเป้าหมาย | ชี้เมาส์ที่ต้นไม้ หิน สัตว์ หรือมอนสเตอร์ | กรอบเรืองแสง พร้อมชื่อ ตัวอักษร และความทนทาน |
| ฟัน/ขุด | ชี้เมาส์ที่เป้าหมายแล้วคลิกซ้าย 1 ครั้งต่อการตี 1 ครั้ง | ตัวละครหันและออกอาวุธไปทางเมาส์ พร้อมเศษบล็อก เสียง และแถบความทนทานลดลง |
| เก็บตัวอักษร | อยู่ใกล้แล้วกดตัวอักษรบนป้ายค้าง 3 วินาที | วงแหวนความคืบหน้า 0–100% พร้อมข้อความปุ่มที่ต้องกด |
| รับอุปกรณ์ | เดินเข้าใกล้อุปกรณ์ที่ตกบนพื้น | รับอัตโนมัติและสวมใส่หากดีกว่าของเดิม |
| ดูวิธีเล่น | ปุ่ม “วิธีเล่น” ในแถบด้านบน | แสดงคำแนะนำ; ระหว่างรอบเวลายังเดินต่อ พร้อมแจ้งให้ชัด |
| ออกจากเกม | ปุ่ม “ออกจากเกม” | ระหว่างเล่นมีหน้าต่างยืนยันออกจากรอบ |

รองรับ WASD และปุ่มลูกศรพร้อมกัน การเดินด้วย WASD อิงตำแหน่งปุ่มจริง (`KeyboardEvent.code`: `KeyW`, `KeyA`, `KeyS`, `KeyD`) จึงเดินได้แม้เปิดแป้นพิมพ์ภาษาไทย การกดสองปุ่มที่เป็นทิศเดียวกัน เช่น W + ↑ ไม่เพิ่มความเร็ว และการเดินทแยงไม่เร็วกว่าเดินตรง หากกดทิศตรงข้ามพร้อมกันให้หักล้างเฉพาะแกนนั้น

ทิศหันแยกจากทิศเดิน: ผู้เล่นเดินถอยหลังหรือเดินด้านข้างด้วย WASD/ลูกศรได้ขณะหันหาเป้าหมาย เมาส์ไม่เปลี่ยนความหมายของปุ่มเดิน คำนวณทิศหันจากตัวละครไปยังจุดเมาส์ในโลก โดยชดเชยตำแหน่ง Canvas ขนาดแสดงผล การฉายภาพมุมเฉียง และตำแหน่งกล้องทุกเฟรม รวมถึงเมื่อผู้เล่นเดินแต่เมาส์อยู่นิ่ง

เมื่อเมาส์อยู่ตรงกลางตัวละคร ให้คงทิศล่าสุดเพื่อป้องกันการหันสั่น หากเมาส์ออกนอกพื้นที่เกมหรืออยู่เหนือหน้าต่าง/ปุ่ม UI ให้คงทิศล่าสุดและไม่ส่งคลิกเข้าระบบโจมตี การขยับเมาส์เพื่อหันอย่างเดียวไม่ยกเลิกการกดค้างเก็บ และไม่เปลี่ยนของชิ้นที่กำลังเก็บ; การคลิกโจมตีระหว่างเก็บให้ยกเลิกการเก็บก่อน เพื่อไม่ให้ตีและเก็บพร้อมกัน

เมื่อปุ่มเดินตรงกับตัวอักษรที่ต้องเก็บ ให้ใช้กติกานี้ รวมถึงตัวอักษรไทยที่อยู่บนตำแหน่ง WASD:

- หากผู้เล่นหยุดนิ่ง อยู่ในระยะเก็บ และกดปุ่มตรงกับตัวอักษรที่ถูกไฮไลต์เป็นการกดครั้งใหม่ ให้เริ่มเก็บแทนการเดิน ปุ่มนั้นทำหน้าที่เก็บตลอดการกดค้างครั้งนั้น
- หากกดเดินค้างอยู่ก่อนแล้วเดินผ่านของ จะยังเดินต่อ ไม่เปลี่ยนไปเก็บอัตโนมัติ ต้องปล่อยปุ่ม หยุด แล้วกดใหม่เพื่อเก็บ
- เมื่อเก็บสำเร็จหรือถูกยกเลิก ให้รอปล่อยปุ่มเก็บก่อนนำปุ่มนั้นกลับมาใช้เดิน ป้องกันตัวละครเคลื่อนที่ทันทีเมื่อวงแหวนเต็มหรือถูกโจมตี
- ใช้ปุ่มลูกศรเดินออกจากของได้เสมอ หาก WASD ตรงกับตัวอักษรใกล้ตัว แสดงคำใบ้ “ปุ่มนี้ใช้เก็บ — ใช้ลูกศรเพื่อเดินออก”
- ตรวจปุ่มเก็บผ่านการแปลงภาษาเดิมและเงื่อนไข Shift ไม่ใช้ตำแหน่ง WASD แทนการตรวจความถูกต้องของตัวอักษร

ปุ่มโจมตีมีระยะและคูลดาวน์ การคลิกรัวไม่ทำให้ตีเกินความเร็วของอุปกรณ์

เมื่อกดค้างเพื่อเก็บ ตัวละครต้องหยุดเดิน การเดิน ปล่อยปุ่ม กดตัวอักษรผิด เพิ่มปุ่มตัวอักษรอีกปุ่ม ถูกโจมตี หรือออกนอกระยะ จะยกเลิกการเก็บและเริ่มใหม่ที่ 0% ไม่เก็บเองเพียงเพราะเดินทับตัวอักษร

## 5. ตัวอักษรและเป้าหมายการเรียนรู้

ข้อเสนอค่าเริ่มต้นสำหรับการทดลองเล่น: เก็บตัวอักษร 20 ชิ้นภายใน 5 นาที โดยนำตัวอักษรจากเนื้อหาบทเรียนปัจจุบัน รวมถึงเนื้อหาที่ครูปรับเอง แสดงชุดภารกิจและจำนวนที่ยังขาด เก็บลำดับใดก็ได้ตามจำนวนที่ระบุ

- ใช้ตัวอักษรที่พิมพ์ได้ในบทเรียน ตัดช่องว่างและอักขระควบคุมออกจากภารกิจ
- กระจายชนิดตัวอักษรที่เลือกในภารกิจให้มีความหลากหลาย ไม่ให้การสุ่มทำให้ฝึกเพียงตัวเดียว
- หากบทเรียนมีตัวอักษรไม่ถึง 20 ชนิด ให้มีตัวอักษรซ้ำในภารกิจตามจำนวนที่ต้องเก็บ
- สร้างแหล่งตัวอักษรให้มีจำนวนเพียงพอสำหรับทุกตัวในภารกิจ และมีสำรองอย่างน้อยหนึ่งชุด
- ของดรอปไม่หายตามเวลาในรอบนั้น และไม่ตกในจุดที่เข้าไม่ถึง
- ไม่เพิ่มคะแนนเกินจำนวนที่ภารกิจต้องการ ตัวอักษรที่ครบแล้วใช้ป้ายสีจางพร้อมข้อความ “ครบแล้ว”
- รองรับภาษาไทยและอังกฤษผ่านระบบแป้นพิมพ์เดิม รวมทั้งการกด Shift เพื่อพิมพ์อักขระพิเศษ
- วรรณยุกต์หรือสระไทยที่วางเหนือ/ใต้พยัญชนะ แสดงบนวงกลมประเพื่อให้อ่านเดี่ยว ๆ ได้ วงกลมประเป็นเพียงส่วนแสดงผล ไม่ใช่ปุ่มที่ต้องพิมพ์
- กรณีเนื้อหาบทเรียนไม่มีอักขระที่เล่นได้ ให้แจ้งก่อนเริ่มเกม และไม่เริ่มรอบที่ไม่มีทางเล่นจบ

## 6. วัตถุ อุปกรณ์ และระบบดรอป

ค่าด้านล่างเป็นค่าตั้งต้นเพื่อปรับสมดุลหลังทดลองเล่น ไม่ใช่ข้อกำหนดตัวเลขจากผู้ใช้

| เป้าหมาย | ความทนทานเริ่มต้น | อุปกรณ์ที่ช่วย | ของดรอป |
| --- | --- | --- | --- |
| หิน/แร่ | 4 | พลั่วขุด | ตัวอักษร และมีโอกาสได้พลั่วขุด |
| ต้นไม้ | 4 | ขวาน | ตัวอักษร และมีโอกาสได้ขวาน |
| สัตว์บล็อกแฟนตาซี | 3 | ดาบ | ตัวอักษร และมีโอกาสได้ดาบ |
| มอนสเตอร์ | 4 | ดาบ | ตัวอักษร และมีโอกาสได้อุปกรณ์อัปเกรด |

เริ่มด้วยเครื่องมือไม้พื้นฐานที่ใช้กับเป้าหมายทุกชนิดได้ ความเสียหาย 1 ต่อครั้ง คูลดาวน์ 0.6 วินาที เมื่อได้เครื่องมือชนิดตรงกับเป้าหมายจะเลือกใช้ให้อัตโนมัติ:

| ระดับ | ความเสียหายต่อครั้ง | คูลดาวน์ | เวลาเก็บตัวอักษร |
| --- | --- | --- | --- |
| ไม้พื้นฐาน | 1 | 0.6 วินาที | 3 วินาที |
| หิน | 2 | 0.45 วินาที | 3 วินาที |
| คริสตัล | 3 | 0.3 วินาที | 3 วินาที |

หินก้อนแรกให้พลั่วหินแน่นอน เพื่อให้นักเรียนได้เห็นผลของการอัปเกรดตั้งแต่ต้นรอบ เป้าหมายถัดไปมีโอกาส 25% ที่จะดรอปอุปกรณ์ตรงชนิด อุปกรณ์หินที่ได้ซ้ำอัปเกรดเป็นคริสตัล สูงสุดระดับคริสตัล ไม่ลดระดับเมื่อเก็บของซ้ำ และไม่ดรอปหัวใจเพิ่มเพื่อคงกติกาโดน 5 ครั้งแพ้

อุปกรณ์ช่วยเฉพาะการฟันหรือขุด เวลากดตัวอักษรค้างยังเป็น 3 วินาทีทุกระดับ

## 7. แมพและมอนสเตอร์

- แมพตั้งต้นขนาด 32 × 32 ช่อง มีทุ่งหญ้า ป่า ลานหิน และทางเดิน เชื่อมต่อถึงกัน
- จุดเกิดเป็นลานปลอดภัย มีหินสำหรับทดลองขุดอยู่ใกล้ ๆ และไม่มีศัตรูเกิดติดตัว
- ต้นไม้และหินมีการชน ต้องเดินอ้อมหรือทำลาย ทางเดินหลักต้องไม่ถูกปิดจนไปไม่ถึงภารกิจ
- สัตว์เดินช้าในบริเวณเล็ก ๆ ไม่โจมตี และหยุดสั้น ๆ เมื่อตีเพื่อให้คลิกซ้ำได้ง่าย
- มอนสเตอร์ตัวแรกเกิดหลังเริ่มเกม 20 วินาที จากนั้นตรวจเพิ่มทุก 25 วินาที โดยมีพร้อมกันสูงสุด 3 ตัว
- จุดเกิดมอนสเตอร์ต้องห่างผู้เล่นอย่างน้อย 6 ช่อง และมีทางเดินถึงผู้เล่น
- เมื่อเห็นผู้เล่นในระยะ 8 ช่อง มอนสเตอร์จะวิ่งเข้าหาและอ้อมสิ่งกีดขวาง
- ผู้เล่นเดินเร็วกว่า: ตั้งต้น 3.5 ช่อง/วินาที เทียบกับมอนสเตอร์ 2 ช่อง/วินาที
- เมื่อผู้เล่นตีโดนมอนสเตอร์ มอนสเตอร์ถอยและชะงักชั่วครู่ เปิดโอกาสให้หลบหรือเก็บของ
- ไม่มีเลือดหรือภาพรุนแรง เป้าหมายแตกเป็นอนุภาคบล็อกและของดรอป

## 8. หัวใจ เวลา และการจบรอบ

เริ่มที่หัวใจ 5 ดวง ทุกการโจมตีที่นับผลลด 1 ดวง หลังโดนตีมีช่วงอมตะ 2 วินาที ตัวละครกระพริบและถูกผลักออก เพื่อไม่ให้หัวใจหายหลายดวงจากการสัมผัสครั้งเดียว หัวใจหมดทันทีที่รับการโจมตีสำเร็จครั้งที่ 5

ตัวจับเวลาเริ่มเมื่อกด “เริ่มสำรวจ” เท่านั้น แสดง 05:00 ถึง 00:00 ที่ 60 วินาทีสุดท้ายเปลี่ยนสีและส่งเสียงเตือนสั้น ๆ คำนวณเวลาจากเวลาจริง ไม่ใช้จำนวนเฟรม เมื่อสลับแท็บ เวลารอบยังเดินต่อ แต่ล้างปุ่มที่ค้างอยู่และไม่จำลองการโจมตีสะสมระหว่างที่มองไม่เห็นเกม

เมื่อกลับมาที่แท็บ หากครบ 5 นาทีแล้ว ให้จบรอบทันที การเก็บต้องเกิดจากการกดค้างจริงขณะเกมมีโฟกัส ไม่ใช้เวลาที่แท็บถูกซ่อนมานับให้ครบ 3 วินาที

- ชนะ: เก็บครบจำนวนภารกิจก่อนหมดเวลาและหัวใจยังเหลือ แสดงตัวอักษรที่เก็บ เวลาที่ใช้ และหัวใจคงเหลือ
- แพ้เพราะหัวใจ: แสดง “หัวใจหมดแล้ว ลองสำรวจใหม่อีกครั้ง”
- แพ้เพราะเวลา: แสดง “หมดเวลาแล้ว” พร้อมจำนวนที่เก็บได้
- ถ้าเวลาหรือหัวใจหมดพร้อมกับจังหวะรับตัวอักษรสุดท้าย ให้สถานะแพ้มีลำดับก่อน เพื่อให้ผลแน่นอน
- หลังชนะหรือแพ้ หยุดการเคลื่อนที่ การโจมตี การเก็บ และระบบสร้างศัตรูทันที
- หน้าจบมี “เล่นอีกครั้ง” และ “กลับบทเรียน”; เมื่อชนะมี “บทเรียนถัดไป” โดยบทสุดท้ายใช้ข้อความจบหลักสูตร

## 9. หน้าจอและข้อความวิธีเล่น

ระหว่างเล่น ด้านบนแสดงหัวใจ เวลา และจำนวนที่เก็บ เช่น 8/20 มุมบนขวาเป็นแผนที่ย่อแสดงผู้เล่น แหล่งตัวอักษร และศัตรูใกล้ตัว ด้านล่างแสดงช่องอุปกรณ์และระดับ พร้อมคำแนะนำตามสถานการณ์

ป้ายตัวอักษรหันตรงเข้าหน้าจอเสมอ ไม่เอียงไปกับพื้น มีพื้นหลังตัดกับฉากและขนาดที่อ่านง่าย เป้าหมายที่คลิกอยู่นอกระยะแสดง “เดินเข้าไปใกล้อีกนิด” เมื่อตัวอักษรอยู่ในระยะ แสดง “กด [ก] ค้าง 3 วินาทีเพื่อเก็บ” พร้อมวงแหวนเหนือของชิ้นนั้น

ข้อความหน้าวิธีเล่นก่อนเริ่ม:

> **ภารกิจ: เก็บตัวอักษรให้ครบ 20 ชิ้นใน 5 นาที!**
>
> 1. ใช้ WASD หรือปุ่มลูกศร ↑ ↓ ← → เดินสำรวจ (W ขึ้น, A ซ้าย, S ลง, D ขวา)
> 2. เลื่อนเมาส์เพื่อหันตัวละคร เดินเข้าใกล้ต้นไม้ หิน สัตว์ หรือมอนสเตอร์ ชี้เมาส์ที่เป้าหมายแล้วคลิกซ้ายเพื่อฟันหรือขุด
> 3. เมื่อมีตัวอักษรตกลงมา ให้เข้าใกล้ หยุดเดิน และกดปุ่มตัวอักษรนั้นค้าง 3 วินาทีจนวงแหวนเต็ม
> 4. เดินไปเก็บดาบ ขวาน และพลั่วที่ดรอปเพื่อทำลายเป้าหมายได้เร็วขึ้น
> 5. ระวังมอนสเตอร์! คลิกตีเพื่อป้องกันตัว หรือเดินหลบ คุณมีหัวใจ 5 ดวง
>
> ปล่อยปุ่ม เดินหนี หรือโดนโจมตีระหว่างเก็บ ต้องเริ่มกดค้างใหม่ อุปกรณ์ไม่ลดเวลาเก็บตัวอักษร
>
> ถ้าปุ่มเก็บตรงกับ WASD ให้หยุดเดิน ปล่อยปุ่ม แล้วกดใหม่ค้างไว้เพื่อเก็บ หากต้องการเดินออกให้ใช้ปุ่มลูกศร

ปุ่มหลัก “เริ่มสำรวจ” และปุ่มรอง “กลับบทเรียน” ใช้จำนวนเป้าหมายจริงแทนเลข 20 หากมีการปรับค่าภายหลัง เสียงเปิด/ปิดตามการตั้งค่าเดิม และทุกสัญญาณเสียงมีภาพหรือข้อความประกอบ

## 10. การเชื่อมต่อโปรเจกต์เดิม

- เปลี่ยนปุ่มเกมท้ายบทเรียนและหน้าจอ `game-ui` ใน `index.html` เป็นเกมนี้เกมเดียว
- ถอดตัวเลือกธีมและ engine ของ Space Defender, Cyber Runner, Samurai Slash และ Minimal Rhythm
- ใช้การผ่านแบบฝึกหัดความแม่นยำ 80% และการปลดล็อกบทเรียนตามเดิม การแพ้เกมไม่ลบความคืบหน้าบทเรียน
- ให้เกมอ่านตัวอักษรจาก `generateContent()` ของบทเรียนปัจจุบัน และใช้ `getVirtualChar()` สำหรับการแปลงภาษาแป้นพิมพ์
- แยกส่วนตรรกะเกม ตัววาดภาพ ตัวรับอินพุต และตัวเชื่อมหน้าบทเรียนไว้ใน `src/lettercraft/` ให้ทดสอบได้ แล้วรวมลง `index.html` ด้วย `scripts/build-lettercraft.cjs`
- เก็บเว็บที่นำไปใช้งานเป็น `index.html` ไฟล์เดียวต่อไป เพื่อให้ตรงกับขั้นตอน GitHub Pages และ Apps Script ใน `DEPLOY.md`
- ไม่ต้องเปลี่ยนโครงสร้าง Google Sheets หรือ API ใน `code.gs` สำหรับขอบเขตเกมนี้ ผลรอบแสดงในเกม การปลดล็อกใช้ระบบแบบฝึกหัดเดิม
- ไม่มีการบันทึกความคืบหน้าซ้ำจากเกมหรือเขียนค่าที่ทำให้ระดับบทเรียนลดลง
- เมื่อออกหรือเล่นใหม่ ต้องยกเลิก animation loop, callback และอินพุตของรอบเก่า เพื่อไม่ให้เกิดศัตรูหรือการโจมตีข้ามรอบ

## 11. ลำดับพัฒนาที่เสนอหลังยืนยันแบบ

1. ปรับชุดทดสอบให้ตรงกติกาใหม่: คลิกทำลายวัตถุแล้วจึงกดตัวอักษรค้างเก็บ ใช้ `node --test tests/block-world.test.cjs`
2. ทำรอบเกมพื้นฐาน: แมพ เดิน กล้อง ชนวัตถุ หันตามเมาส์ คลิกตีในทิศที่ชี้ และของตัวอักษรดรอป ให้ทดลองวงจรครบได้ก่อน
3. เพิ่มการเก็บค้าง 3 วินาที การเลือกของใกล้ตัว และป้ายภาษาไทย/อังกฤษ ทดสอบการปล่อยปุ่ม การเสียโฟกัส หลายปุ่มพร้อมกัน และการแยก WASD สำหรับเดินออกจากการกดค้างเก็บ
4. เพิ่มอุปกรณ์ดรอป การอัปเกรด และความเร็วตีตามประเภทเป้าหมาย
5. เพิ่มมอนสเตอร์ การเดินอ้อมสิ่งกีดขวาง การโจมตี หัวใจ 5 ดวง และช่วงอมตะหลังโดนตี
6. เพิ่มเวลา 5 นาที เงื่อนไขชนะ/แพ้ หน้าจบ การเล่นใหม่ และการกลับบทเรียน
7. แทนที่หน้าเกมเดิม เพิ่มวิธีเล่น HUD แผนที่ย่อ เสียง และภาพเคลื่อนไหว
8. ทดลองเล่นจริงในเบราว์เซอร์ ปรับความยากและขนาดตัวอักษร ทดสอบ viewport เล็กและใหญ่ แล้วอัปเดต `DEPLOY.md` ตามผลจริง

## 12. เกณฑ์ตรวจรับ

- มีเกมเดียวและไม่มีตัวเลือก 4 ธีมเดิม
- เดินสำรวจและชนวัตถุได้ตามภาพ คลิกโดนเป้าหมายถูกตัวทั้งก่อนและหลังกล้องเลื่อน/ปรับขนาดจอ
- ตัวละครและอาวุธหันตามเมาส์ได้รอบตัวโดยไม่ต้องคลิก เดินถอยหลัง/ด้านข้างได้โดยยังหันหาเป้าหมาย ปุ่มเดินยังอิงทิศหน้าจอเดิม
- ทิศหันและทิศโจมตีตรงกับจุดที่เมาส์ชี้หลังกล้องเลื่อน ปรับขนาด Canvas หรือเดินโดยเมาส์อยู่นิ่ง; เมาส์ตรงกลางตัวละครไม่ทำให้ทิศสั่น
- เลื่อนเมาส์ระหว่างกดค้างเก็บไม่รีเซ็ตวงแหวนหรือเปลี่ยนของเป้าหมาย แต่คลิกโจมตีจะยกเลิกการเก็บ และการคลิก UI ไม่ทำให้โจมตีฉาก
- WASD และลูกศรเดินในทิศทางเดียวกันและเร็วเท่ากัน ทั้งเมื่อแป้นพิมพ์ระบบเป็นไทยและอังกฤษ กดปุ่มทิศเดียวกันซ้ำข้ามสองชุดหรือเดินทแยงแล้วไม่เพิ่มความเร็ว
- หยุดใกล้ของแล้วกดปุ่ม WASD ที่ตรงกับอักษรค้างครบ 3 วินาทีเก็บได้โดยไม่เดิน รวมถึงอักษรไทยบนตำแหน่งเดียวกัน การเดินค้างผ่านของไม่เปลี่ยนเป็นเก็บเอง และเก็บเสร็จหรือถูกยกเลิกแล้วไม่เดินต่อจนกว่าจะปล่อยและกดใหม่
- ใช้ลูกศรเดินออกจากของที่ปุ่มเก็บตรงกับ WASD ได้ และการเดินนั้นยกเลิกวงแหวนเก็บตามกติกา
- คลิกโจมตีได้เฉพาะในระยะและเมื่อหมดคูลดาวน์ ไม่สามารถตีผ่านอุปสรรคที่บังระหว่างผู้เล่นกับเป้าหมาย
- การคลิกไม่เก็บตัวอักษร การกดตัวอักษรไม่ฟันหรือขุด การเดินทับไม่เก็บเอง
- กดตัวอักษรถูกค้าง 2.9 วินาทียังไม่ได้ของ ครบ 3 วินาทีได้ของหนึ่งชิ้นและนับครั้งเดียว
- ปล่อยปุ่ม ผิดตัว เคลื่อนที่ ออกจากระยะ โดนตี หรือเสียโฟกัส ยกเลิกความคืบหน้าการเก็บ
- ของตัวอักษรหลายชิ้นที่อักษรเหมือนกันไม่ถูกเก็บพร้อมกัน เลือกชิ้นใกล้ที่สุดในระยะและแสดงกรอบชัดเจน
- เครื่องมือที่ดีขึ้นช่วยฟันหรือขุดจริง แต่เวลาเก็บยังคง 3 วินาที
- หัวใจลดครั้งละ 1 มีช่วงอมตะ และการโจมตีสำเร็จครั้งที่ 5 ทำให้แพ้
- รอบหยุดเมื่อครบ 300 วินาที ทั้งกรณีเล่นต่อเนื่องและกลับจากแท็บที่ซ่อน
- ทุกตัวในภารกิจมีแหล่งที่เข้าถึงได้เพียงพอ ทดสอบหลาย seed ของการสร้างแมพ
- เป้าหมายใช้เนื้อหาบทเรียนจริง รองรับวรรณยุกต์ไทยและ Shift โดยไม่มีคำอื่นนอกบทเรียนเข้ามาแทนโดยเงียบ ๆ
- เปิดใหม่ เล่นซ้ำ ออกกลางเกม และสลับไปบทเรียนถัดไปแล้วไม่มี event/ตัวจับเวลารอบเก่าหลงเหลือ
- ความคืบหน้าการเรียนและทางเลือก GitHub Pages/Apps Script ยังใช้ได้ตามเดิม
- วิธีเล่นอธิบายความแตกต่างระหว่างคลิกทำลายกับกดค้างเก็บอย่างตรงกับเกม
